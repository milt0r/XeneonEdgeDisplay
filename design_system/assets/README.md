# assets/

Brand-adjacent visual assets for the Xeneon Edge design system.

- `wordmark.svg` — the `XENEON//EDGE` wordmark in Monoton + VT323, with a faux phosphor glow filter. Use as the masthead in slides, splash screens, and headers.

There is **no separate icon mark** — the app's identity is purely typographic. If you need a square monogram, use the `XE` ligature from VT323 on a `#020a04` background with a `#7cff8a` foreground.

Imagery used inside the product (album art, sports team logos, HA-entity photos) is fetched at runtime from third parties — none of it is bundled. Don't generate substitute imagery; leave a placeholder slot and let real content fill it.
